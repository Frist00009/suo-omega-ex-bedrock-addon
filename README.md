# Suo Omega EX — Bedrock Add-on

This repository contains a Bedrock Add-on prototype for a skill system based on the provided Suo Omega EX list.

## Included

- Behavior Pack with custom item: `suo:galaxy_remote`
- Skill command system: `/suo cast <id>` and `/suo menu`
- 65 skill entries
- Cooldown handling
- Basic AoE damage logic
- Resource Pack UI + particle placeholder

## Setup

1. Download ZIP from GitHub.
2. Extract the folder.
3. Rename the folder to a Bedrock-compatible add-on package name if needed.
4. Open Minecraft Bedrock and import the two packs:
   - `behavior_pack`
   - `resource_pack`
5. Enable Experimental Gameplay / GameTest features in the world.
6. Use:
   - `/give @s suo:galaxy_remote`
   - `/suo cast 63`
   - `/suo menu`

## Notes

- This is a prototype for gameplay/design testing.
- The project includes placeholder visuals and can be extended with custom PNG icons and richer particle effects.
- For the best result on mobile, convert the resource set into a polished final art pack.
